# Deloitte Data Analytics Job Simulation – Daikibo Telemetry Dashboard

## Project Overview

This project was completed as part of the Deloitte Data Analytics virtual job simulation through Forage.

The project focuses on analyzing industrial telemetry data from Daikibo Industrials to identify potential machine downtime and investigate which factories and device types contributed to the downtime.

The analysis was performed using Tableau, with a calculated field used to convert unhealthy machine-status events into potential downtime minutes.

---

## Business Problem

Daikibo Industrials operates industrial facilities where machine performance and downtime can affect operational efficiency.

The objective of this analysis was to:

- Identify factories with the highest potential downtime.
- Analyze downtime by device type.
- Allow users to investigate device-level downtime for a selected factory.
- Convert telemetry status information into a meaningful downtime metric.
- Present the findings through an interactive Tableau dashboard.

## Dataset

The analysis used industrial telemetry data containing information such as:

- Factory
- Device Type
- Status
- Location
- Telemetry information

The business requirement defined each unhealthy machine status as representing 10 minutes of potential downtime.
